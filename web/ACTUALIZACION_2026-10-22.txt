KEVINTECH WEB - ACTUALIZACIÓN

Cambios incluidos:
- Formulario Crear cuenta: SSH, Xray (VMess), SOCKS5 y WireGuard.
- SOCKS5: crea usuario del sistema con contraseña y expiración. Requiere que el servicio SOCKS5 instalado autentique contra usuarios del sistema.
- WireGuard: genera un peer y archivo cliente en /etc/kevintech/wg-peers/<usuario>.conf. Requiere WireGuard ya instalado, interfaz wg0 activa y /etc/wireguard/wg0.conf configurado.
- SQLite: mayor timeout, BEGIN IMMEDIATE y reintentos para reducir el error database is locked durante inicio de sesión.
- Excepciones inesperadas en GET/POST se registran y devuelven HTTP 500 controlado, en lugar de cerrar la conexión sin respuesta.
- La opción antes llamada V2Ray se muestra como Xray (VMess); se conserva compatibilidad con cuentas ya guardadas.

IMPORTANTE SOBRE 502 BAD GATEWAY:
Un 502 también puede deberse a Nginx/HAProxy apuntando al puerto equivocado o a que el servicio web está detenido. Este paquete corrige errores de aplicación conocidos, pero no puede confirmar ni arreglar la configuración externa del proxy sin verla.

Instalación recomendada:
1. Haz copia de seguridad de /etc/kevintech/web y de /etc/kevintech/web/data/web.sqlite3.
2. Copia el contenido de esta carpeta a /etc/kevintech/web/ conservando permisos y propietario.
3. Ejecuta: python3 -m py_compile /etc/kevintech/web/server.py
4. Reinicia el servicio web (nombre habitual: systemctl restart kevintech-web; comprueba el nombre real con systemctl list-units --type=service | grep -i kevintech).
5. Comprueba: curl -i http://127.0.0.1:18080/health
6. Si sigue el 502, revisa: journalctl -u kevintech-web -n 100 --no-pager; nginx -t; journalctl -u nginx -n 100 --no-pager.

No sobrescribas la base de datos ni el archivo de configuración con archivos vacíos.
