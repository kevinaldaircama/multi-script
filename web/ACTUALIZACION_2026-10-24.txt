KEVINTECH WEB — ACTUALIZACIÓN 5.0
================================

CAMBIOS
- En Crear cuenta aparecen SSH, V2Ray/Xray (VMess), SOCKS5, WireGuard, ZiVPN UDP y OpenVPN.
- ZiVPN agrega la contraseña a /etc/zivpn/config.json y reinicia el servicio con respaldo previo.
- OpenVPN genera el certificado EasyRSA y un perfil .ovpn que se descarga desde la ficha de la cuenta.
- Las fichas muestran datos de conexión con formato tipo script. WireGuard y V2Ray/Xray muestran QR local si `qrencode` está instalado.
- El inicio de sesión ahora cierra la conexión de lectura antes de crear la sesión, reintenta escrituras SQLite ocupadas y muestra un error legible en lugar de una excepción sin manejar.
- La cookie de sesión Secure se activa cuando el proxy informa X-Forwarded-Proto: https o el servidor atiende directamente en el puerto 443.

REQUISITOS IMPORTANTES
- El servicio web debe ejecutarse como root para administrar servicios y leer las claves.
- ZiVPN: debe existir /etc/zivpn/config.json y el servicio systemd `zivpn` debe estar instalado.
- OpenVPN: deben existir /etc/openvpn/server/server.conf, /etc/openvpn/server/tc.key y la PKI EasyRSA en /etc/openvpn/server/easy-rsa.
- WireGuard: debe estar configurado y activo en wg0.
- QR local opcional: `apt-get update && apt-get install -y qrencode`.
- ZiVPN autentica con contraseñas compartidas. La expiración de la ficha es informativa; el servicio ZiVPN no expira esa contraseña automáticamente.
- SOCKS5: la creación del usuario del sistema no configura por sí sola autenticación en todos los daemons SOCKS5. Verifica la integración de tu servicio.
- No se ha probado contra tu VPS real; los servicios y rutas reales deben validarse en el servidor antes de usarlo en producción.

INSTALACIÓN SEGURA EN EL VPS
1. Sube y descomprime este ZIP en una carpeta temporal.
2. Haz copia de seguridad de la web y de su base de datos:
   cp -a /etc/kevintech/web /etc/kevintech/web.backup-$(date +%Y%m%d-%H%M%S)
3. Copia la carpeta web actualizada sobre la existente, preservando el directorio data:
   cp -a web/. /etc/kevintech/web/
4. Comprueba sintaxis:
   python3 -m py_compile /etc/kevintech/web/server.py
5. Reinicia y comprueba:
   systemctl restart kevintech-web.service
   systemctl --no-pager --full status kevintech-web.service
   curl -fsS http://127.0.0.1:18080/health
6. Si el login sigue fallando, revisa:
   journalctl -u kevintech-web.service -n 100 --no-pager
   ls -l /etc/kevintech/web/data/web.sqlite3*

No borres /etc/kevintech/web/data: ahí se guarda la base de datos y la clave que cifra las credenciales.
