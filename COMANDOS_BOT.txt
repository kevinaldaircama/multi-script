## 💰 PUBLICIDAD

Las operaciones públicas usan publicidad para mantener el servicio gratuito:

- 👤 Cuenta normal: **3 Ads**
- 🚀 Cuenta V2Ray: **2 Ads**
- 🎁 Canjear 7 días: **1 Ad**
- ♻️ Renovar: **5 Ads**
- ⏳ Renovación desde aviso de vencimiento: **7 Ads**

Los anuncios se presentan por pasos y cada paso genera un enlace nuevo. Al completar uno, el bot muestra automáticamente el siguiente.

## 🟢 ONLINE

El botón **Online** está organizado por cuenta:

```text
🟢 Kevin — 1
   🌐 IP

🟢 caca — 2
   🌐 IP, IP

⚪ pepe — 0
```

- El número indica cuántas conexiones SSH están activas.
- Los usuarios normales ven solamente sus cuentas.
- El Super Admin ve todas las cuentas creadas y las conexiones activas.
- Las IP activas se muestran al Super Admin y al propietario de la cuenta.

## 📋 LISTA DEL SUPER ADMIN

El botón **Lista** muestra todas las cuentas creadas por los usuarios registrados, agrupadas por propietario.

Las contraseñas no se exponen: se muestran como `xxx`.

## 👨‍💼 SUPER ADMIN

El Super Admin utiliza el menú:

**⚙️ Ajustes**

Desde allí puede administrar:
- Administradores
- Usuarios registrados
- Banear/desbanear usuarios
- Cuotas
- Monetag
- Backups y restauración
- Seguridad
- Herramientas
- Protocolos
- Actualización del sistema
- Reinicio del VPS

## 🔐 SEGURIDAD

- Las funciones administrativas están protegidas para el Super Admin.
- Los usuarios no pueden acceder a los callbacks administrativos directamente.
- Las contraseñas no se muestran en la lista global.
- Las operaciones de publicidad utilizan tokens temporales.

## ℹ️ IMPORTANTE

- Los días y el límite no se solicitan al usuario público; se aplican automáticamente mediante las cuotas configuradas.
- Crear cuenta normal, crear V2Ray, renovar, online y eliminar mantienen su flujo principal.
- El aviso de vencimiento puede llevar directamente al flujo de renovación con 7 anuncios.
